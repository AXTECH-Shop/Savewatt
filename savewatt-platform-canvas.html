Analysis Engine

What the Platform Actually Analyses

Two-layer architecture: AI extraction (Claude / Gemini for unstructured → structured) then deterministic rule engine for financial checks. Never trust an LLM for a financial calculation.

Layer 1 — AI extraction (reuse Gemini unified processor from Veloren)
🤖

Structured field extraction from PDF invoices

Extract 30+ fields per invoice: PDL, period, index, puissance, tariff, line amounts, tax components. Same base_processor / gemini_unified_processor pattern from iverif codebase. Configure new SaveWatt field schema.

Reuse from iverif
🔍

Contract term extraction

Extract key contract parameters from PDF contracts: tariff option, puissance souscrite, prix/segment, remises, duration. Cross-referenced against invoices.

New field schema
📝

Supplier letter classification

Classify incoming supplier responses: refusal, partial acknowledgement, credit note, request for more info, dispute. Extract amounts, dates, reference numbers.

New document type
Layer 2 — Deterministic rules (Python, versioned, auditable)
📐

TURPE rate validation

For each invoice period, check: TURPE component amount = f(puissance souscrite, FTA option, period). Compare against CRE published rates for TURPE 5/6/7 applicable in that period. Flag delta > €X or > Y%.

High value
⚡

Puissance calibration vs load curve

Pull actual load curve from Enedis (via Symphonics). Find true peak power draw over 12–24 months. If subscribed power > actual peak × 1.1: over-subscribed = over-billing. If subscribed power < actual peak: dépassement penalties. Both are claims.

High value
🏭

Accise / TICFE eligibility check

Client NAF code + annual consumption + usage type → check against DGDDI exemption table. If client qualifies for reduced rate (e.g. industrial process > 222 MWh/yr) but was billed at normal rate → DGDDI refund claim for 5 years.

High value
📅

Duplicate period detection

Across all invoices for a PDL, check: no two invoices cover overlapping billing periods. Flag overlaps as billing error → supplier claim.

Medium value
🔢

Index continuity check

Invoice N end index should = Invoice N+1 start index (±tolerance for estimated readings). Gaps or jumps indicate: meter read error, estimated reading billed as actual, or reset not credited.

Medium value
📋

Tariff option optimisation

Given load curve shape: is current tariff option (Base vs HP-HC vs Tempo vs EJP) optimal? Simulate alternative options against actual consumption pattern. If cheaper option exists → contract renegotiation recommendation.

Optimisation
💰

Contract discount enforcement

Extract negotiated discount terms from contract. Verify each invoice applies the correct discount. Missing discount = billing error → supplier claim.

Medium value
🌿

CEE eligibility scan

If client has upcoming or recent renovations (LED, insulation, HVAC): check against CEE fiche catalogue. Flag CEE opportunity with estimated kWh cumac value. Hand off to iverif.io dossier preparation flow.

CEE track
Layer 3 — Financial quantification

For every confirmed anomaly: calculate the exact € amount recoverable per period, per PDL, per anomaly type. Sum to: (a) retrospective recovery = claim on past overpayments, (b) prospective savings = annual saving from contract fix, (c) CEE valorisation value. This is the report the client sees. This is also what triggers the success fee calculation.

Revenue Model

How SaveWatt Makes Money

Three revenue streams, all tied to value delivered. Success-fee model means zero friction for clients to start.

Stream 1 — Recovery fee

Fee charged on amounts actually recovered from suppliers / GRD / DGDDI. Zero advance from client.

30–40%
of recovered sums
Example: Commune with €290K/yr bill. Recover €41K → SaveWatt earns €12–16K per client.

Industry benchmark: DUNE Energie charges 33% of first-year savings.

Stream 2 — Ongoing savings fee

% of annual savings from contract optimisation (TURPE recalibration, tariff change, puissance reduction), charged for 12–24 months.

15–25%
of annual savings, for 1–2 years
Example: Industrial site saves €18K/yr on TURPE. SaveWatt earns €3–4.5K/yr for 2 years = €6–9K additional.

Stream 3 — CEE brokerage

When SaveWatt identifies CEE-eligible works, it acts as mandataire CEE. Monetise kWh cumac by selling to obligés (energy suppliers). Commission on the CEE value.

15–25%
of CEE prime value (~€7–10/MWh cumac)
Handed to iverif.io for dossier assembly. Tight integration between the two products = cross-sell revenue.
